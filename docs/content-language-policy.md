# 表示文言とカタログ本文

| 内容 | 管理場所 |
| --- | --- |
| ボタン・見出し・フォームラベル・通知・メール・操作案内 | `config/locales/` |
| 機能の概要・バージョン別の比較・採用条件・移行時の注意・デモ内の技術解説 | `config/catalog/features.yml` |
| 比較対象バージョンの情報 | `config/catalog/versions.yml` |

たとえば「主な変更点」という見出しは I18n で表示します。その下で「何が変わったか」を説明する本文は、対象バージョン・コード例・出典と一緒にカタログで管理します。本文を翻訳辞書にも複製しません。

説明と操作案内は日本語で記述し、製品名・API 名・コマンド・パスは公式の表記を維持します。モデルの属性ラベルは `activerecord.attributes` の定義を再利用します。Rails を経由せず配信する静的エラーページは日本語の HTML で管理します。
