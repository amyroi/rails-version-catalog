# 日本語表示への段階的な切り替え

## 1. 互換版（この変更）

既定ロケールは `en` のまま、Active Job のペイロードに保存された
`en` と `ja` の両方を受け付けます。言語選択 UI は追加しません。
この段階では表示・メール・ジョブ出力の英語を維持します。

先にすべてのワーカーを互換版へ更新してください。
`SOLID_QUEUE_IN_PUMA` を有効にした Web プロセス内のワーカーも含みます。
配備確認前に後続版の既定を `ja` に切り替えてはいけません。

## 2. 日本語版（後続の別 PR）

日本語の辞書・カタログ・操作案内を用意したうえで既定を `ja` に変更します。
状態バッジ・実行結果・ログは英語のままで構いません。
互換版の `en` ジョブを日本語版で、日本語版の `ja` ジョブを互換版で
復元し、実行・Turbo 配信・再設定メールのテスト配送を確認します。
外部のメールサーバーや本番キューをテストには使いません。

切り戻し先には互換版を指定してください。`ja` のジョブが残っている間は、
互換版より前へ戻してはいけません。予約済み・失敗後の再試行も含めます。
本番配備と切り戻しには別途承認を得ます。
